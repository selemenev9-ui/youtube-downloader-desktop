# YouTube Downloader

A polished, privacy-friendly desktop utility for downloading YouTube videos and audio in the quality you choose.

## Highlights

- Up to 4K video downloads when available
- MP3 audio extraction
- Built-in video preview and download progress
- No ads, no tracking, free forever
- Portable Windows build — no installation required
- Local processing powered by `yt-dlp` and FFmpeg

## Download

Open the latest entry on the [Releases](../../releases) page and download the portable `.exe` file. The first launch can take a little longer while the portable package is unpacked.

## Development

Requirements: Node.js 20+ and the following Windows binaries inside `bin/`:

- `yt-dlp.exe`
- `ffmpeg.exe`
- `ffprobe.exe`

```bash
npm install
npm start
```

Create a portable build:

```bash
npm run dist
```
