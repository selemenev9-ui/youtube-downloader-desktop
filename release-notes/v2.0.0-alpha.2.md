# VantaFetch v2.0.0-alpha.2 — Public Preview

VantaFetch is now a private, local universal media downloader and optimizer for Windows.

## What is new

- Download public media from YouTube, TikTok, Instagram, Twitch, Kick and many other supported websites.
- Choose the best available quality or a specific resolution.
- Correct vertical preview for Reels, Shorts and TikTok videos.
- Record live streams from the current moment for 5, 15, 30 or 60 minutes.
- Fit videos to 8 MB, 20 MB, 50 MB, 500 MB or a custom size.
- Extract audio locally to FLAC or 24-bit WAV.
- Create short GIF and animated WebP files.
- Add a PNG/WebP watermark with position, size and opacity controls.
- Automatic update notifications without silent downloads or installation.
- No advertising, tracking, accounts or browser authorization.

## Important preview notes

- This is a portable preview build: no installation is required.
- Windows SmartScreen may warn about an unknown publisher because the app is not code-signed.
- Only public media is supported. VantaFetch will not request credentials or import browser sessions.
- Downloads and processed files are saved to the standard Windows Downloads folder.
- Please download only content you are permitted to save and follow the platform's terms and applicable law.
