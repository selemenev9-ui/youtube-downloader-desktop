# VantaFetch 2.0.0

VantaFetch is now a universal, private desktop media downloader and local creator toolkit. No ads, no tracking, no account prompts, and no content is uploaded to a remote conversion service.

## What's new

- Download public media from YouTube, TikTok, Instagram, Twitch, Kick, and many other sites supported by yt-dlp.
- Correct previews for both landscape and vertical videos.
- Choose the best available quality or a specific resolution when the source provides it.
- Record live streams in controlled 5, 15, 30, or 60 minute sessions.
- Fit videos to Discord and custom file-size limits.
- Extract audio as FLAC or WAV.
- Create GIF and WebP animations locally.
- Add a PNG watermark with placement and opacity controls.
- Updated queue, history, progress, cancellation, and error states.

## Updates that do not require reinstalling

VantaFetch 2.0 introduces verified modular updates. Future interface and app-logic releases can be downloaded from inside the app and applied with **Update & restart**. These patches are typically well under 1 MB instead of downloading the full portable application again.

The yt-dlp engine updates independently in the background after verification. A full portable download is only required when the protected bootstrap, Electron runtime, or FFmpeg bundle changes.

Every modular package is checked against its published SHA-256 hash before activation. If a new module cannot start correctly, VantaFetch automatically returns to the previous working module on the next launch.
